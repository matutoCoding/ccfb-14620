# 热收缩套标预变形与收缩仿真工作台

浏览器端套标预变形系统：平面稿 → 收缩场反演预变形 → 炉程仿真 → 上机核对闭环。
TypeScript + 手写 WebGL2 着色器 + IndexedDB，无后端、无外部数据上传。

## 启动

```bash
pnpm install
pnpm dev          # 开发
pnpm build        # 类型检查 + 生产构建
pnpm selftest     # 纯 Node 内核自测（无需安装依赖，Node >= 22 支持 strip-types）
pnpm test         # vitest（需先 install）
```

## 页面结构

| 路由 | 页面 | 能力 |
| --- | --- | --- |
| /bottles | 瓶型库 | 母线绘制/CSV 导入，圆/椭圆/圆角矩形截面，逐高度周长与需求收缩率，超膜材极限标红 |
| /films | 膜材参数 | PETG/PVC/OPS 批次，TD/MD 收缩-温度曲线录入，核对修正曲线对照 |
| /artwork | 稿件预变形 | PNG/SVG 导入，逆场逐像素 warp，变形网格，刚性区保形，条码评级，制版稿与工艺卡导出 |
| /simulation | 收缩仿真 | 蒸汽/热风多温区配置，时间轴播放，接触钉扎，起皱/空鼓标注，膜面光泽/白墨/透明窗/液体渲染 |
| /verification | 上机核对 | 合成带噪声透视的网格试标照片，交点检测，分区偏差热力图，反修膜材曲线并驱动下一版 |
| /settings | 设置 | 仿真网格精度，验收指标，IndexedDB 数据管理 |

## 核心模型

- **几何**：母线线性插值 + 截面参数化（圆/椭圆/圆角矩形），弧长均匀重采样保证不同高度材料方向对齐。
- **动力学**：一阶松弛 `dε/dt = k(ε_eq(T) - ε)`，温区平衡收缩率由膜材 TD/MD 曲线查表，蒸汽/热风分区换热系数。
- **接触**：自由节点半径进入瓶面即钉扎到弧长对应点；邻居松弛两轮传递膜张力；逐环按材料盈余率判定起皱、按钉扎环上的自由节点判定空鼓。
- **预变形**：仿真正向映射（材料弧长 → 瓶面弧长）建场，双线性反演得到印刷采样坐标；刚性区以中心位移做整体相似变换保形。
- **核对闭环**：网格交点检测 → 高度分箱偏差 → TD 曲线分段修正（0.6 增益防过冲），修正曲线持久化后下一轮仿真/预变形自动生效。

## 验收指标（scripts/selftest.ts 量化）

- Logo 中心全链路偏差 < 0.5mm（实测 0.000mm，全域网格均值 0.03mm / 最大 0.63mm）
- 直筒瓶条码宽窄比误差 ≤ 5%（实测 0%，A 级）
- 两轮修正后平均偏差 ≤ 首轮 50%（实测降至约 40%）
- 钉扎节点贴合瓶面误差 < 0.3mm（实测 0.000mm），整体钉扎率 > 95%
